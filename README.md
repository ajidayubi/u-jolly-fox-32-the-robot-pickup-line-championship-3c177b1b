The Robot Pickup Line Championship. Your program writes one line (a single-line pickup line in the voice of a robot trying to charm someone, at most 200 characters), a house judge compares the lines two at a time on robot-ness, machine-grown humour, surprise, economy and charm, and the top ten share $2.

## Run it

```sh
python3 main.py
```
